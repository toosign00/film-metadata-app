다크모드를 어떻게 할까요?

현재 앱은 다크모드가 기본입니다 — 리디자인 후 어떤 방식으로 운영할지 결정

A

라이트 모드 기본 + 다크모드 지원 유지

Cool Clean 라이트가 메인. 다크모드는 system preference 따라 자동 전환 + 수동 토글 모두 지원. 현재 토글 버튼 유지.

B

라이트 모드만

다크모드 완전 제거. 심플하게 한 가지만 완성도 있게. 헤더의 테마 토글 버튼도 제거. 구현 범위 절반으로 줄어듦.

C

다크모드 기본 유지 + 라이트모드 개선

현재처럼 다크가 기본. 라이트도 Cool Clean으로 개선. 필름 현상실 감성이 다크와 더 잘 어울린다는 의견도 있음.

💡 Minimal/Clean Light 방향이면 A가 자연스럽습니다. 다만 현재 다크모드 코드가 잘 구현되어 있어서 버리기엔 아깝기도 해요.
